# HR Attrition Analysis Dashboard 📊

## 📌 Project Overview
This project focuses on analyzing employee attrition using HR data and presenting insights through an interactive dashboard. The goal is to identify key factors contributing to employee turnover and help HR teams make data-driven decisions to improve retention.

The dashboard provides a clear view of attrition trends across departments, job roles, age groups, salary slabs, and job satisfaction levels.

---

## 🎯 Objectives
- Analyze employee attrition patterns
- Identify departments and roles with high attrition
- Understand the impact of age, salary, and job satisfaction on attrition
- Present insights using an interactive and user-friendly dashboard

---

## 📂 Dataset Information
- Records: **1,400+ employee records**
- Data includes:
  - Employee Age
  - Gender
  - Department
  - Job Role
  - Monthly Income
  - Job Satisfaction
  - Attrition Status

*(Dataset used for learning and academic purposes)*

## 🛠 Tools & Technologies

- **DAX** (Calculated Measures & KPIs)
- **Data Visualization Techniques**

---

## 📈 Key KPIs & Metrics
- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate (%)
- Average Employee Age
- Job Satisfaction Score

---

## 🔍 Dashboard Features
- Department-wise attrition analysis
- Job role and age group attrition trends
- Salary slab vs attrition comparison
- Job satisfaction impact on attrition
- Interactive slicers and filters for deeper analysis
- Clean and intuitive visual layout

---

## 📊 Key Insights
- Certain departments and job roles show higher attrition rates
- Employees in lower salary slabs have comparatively higher attrition
- Attrition is more prominent in specific age groups
- Job satisfaction has a direct impact on employee retention
